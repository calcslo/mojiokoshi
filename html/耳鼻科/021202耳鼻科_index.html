試験に出る箇所（重要トピック）

・大唾液腺の解剖と管の名称：耳下腺はステノン管、顎下腺はワルトン管に対応し、それぞれの走行と開口部を理解する必要がある。（講師が「耳下腺もこれを覚えないといけない。耳下腺管の向きとかも覚えていく」と発言したため）

・唾液腺シンチグラフィの評価指標：テクネチウムを用いた検査で、ピークカウントとエジェクション・フラクション（排出率）を見て、産生機能と閉塞の有無を判断する。（講師が講義の最後に「大事なのは解剖とシンチ検査」と強調したため）

・シェーグレン症候群の臨床的重要性：自己免疫疾患であり、眼・口の乾燥症状や自己抗体（SS-A/SS-B）、特有の造影所見が重要である。（講師が「内科さんが絡んでくるので、テストをしても出やすいから、勉強している方が良い」と発言したため）

・流行性耳下腺炎（ムンプス）の診断的特徴：両側性の耳下腺腫脹を認める場合は流行性の蓋然性が極めて高く、臨床的診断の重要な根拠となる。（講師が「両側耳下腺が腫れたら、もうムンプスだ。蓋然性が高い」と強調し、片側性との鑑別を繰り返し説明したため）

・IgG4関連疾患（ミクリッツ病）の病態：涙腺や唾液腺の対称性腫脹を特徴とし、血清IgG4値が診断に直結する現代的な重要疾患である。（講師が最後に「IgG4関連疾患、かなり有用かなと思っています」と重要性を明言したため）

・唾液腺造影におけるApple tree appearance：シェーグレン症候群において、主導管は保たれるが末梢の腺房が破壊され、リンゴの木のように見える特徴的な所見である。（PDF p.3に画像と共に「Apple tree lesion」として記載され、講師も「有名なのはシェーグレンに出てくるApple tree appearance」と説明したため）

試験に出ない箇所

・小唾液腺の個別の詳細名称：口唇腺、口蓋腺、舌腺などの名称は存在するが、大唾液腺ほど厳密に覚える優先度は高くない。（講師が「小唾液腺として、名前をこだわっていいけれど」と述べ、執着しなくてよいことを示唆したため）

・唾液腺造影の腫瘍診断への応用：悪性腫瘍による導管の浸食像などの詳細は、現在の臨床現場での実施頻度から見て優先度が低い。（講師が「現実は多分、これやって、これとそれぐらいしかやらないので、これぐらいのところにやるといいと思います」と範囲を限定したため）

・反復性耳下腺炎の詳細な病態生理：小児の反復性耳下腺炎は経験的に知られているが、学術的な解明は不十分である。（講師が「病態を含め、解明できていない」「何の効果もわからない」と発言し、詳細な説明を避けたため）

・唾液腺腫瘍の網羅的な分類リスト：PDFには膨大な腫瘍の分類が記載されているが、講義では主要な数種類にのみ触れられた。（根拠：PDF p.4に「唾液腺腫瘍(1)～(3)」として数十種類の分類が列挙されているが、講師が「腫瘍はたくさんありますけれども、実際は多形腺腫があって、ワルチン腫瘍、その他...」と主要なものに限定して話したため）

全体の詳細なまとめ

唾液腺の解剖学的分類と管の走行

唾液腺は大きく大唾液腺と小唾液腺に分類される。大唾液腺には耳下腺、顎下腺、舌下腺の3つがあり、小唾液腺には口唇腺、口蓋腺、舌腺、頬腺、臼後腺が含まれる。耳下腺からは耳下腺管（ステノン管）が起始し、頬粘膜へ開口する。顎下腺からは顎下腺管（ワルトン管）が起始し、口腔底へ開口する。講師は「耳下腺管の向きなども含め、解剖を覚える必要がある」と強調した。（PDF p.1「唾液腺の解剖」）

唾液の作用と成分構成

唾液は1日に約1～1.5L分泌され、その約7割が大唾液腺由来である。作用は多岐にわたり、デンプンの分解（アミラーゼ）、ムチンによる粘膜保護、自浄作用、IgAによる抗菌免疫作用、pH緩衝作用、カルシウム塩・リン酸塩による歯の再石灰化、さらに成長因子（EGF）による修復作用がある。成分の99.5％は水分であるが、有機成分としてタンパク質や酵素、無機成分として重炭酸、カリウム、カルシウム等が含まれる。（PDF p.1「唾液の作用」「唾液の成分」）

唾液腺の機能検査法

分泌能検査にはサクソンテストやガム法が用いられる。画像検査では、唾液腺シンチグラフィが重要であり、テクネチウム（99mTc）を静注後、レモン汁やクエン酸による酸刺激（負荷）を与え、唾液の蓄積（ピークカウント）と排出（エジェクション・フラクション）を評価する。唾石症などの閉塞性疾患では排出の低下が見られる。また、唾液腺造影も行われ、造影剤を注入して導管系の形態を確認する。シェーグレン症候群で見られるApple tree appearanceは特徴的な所見である。（PDF p.1「唾液の検査」、p.2「画像検査」）

流行性耳下腺炎（ムンプス）と小児の炎症性疾患

流行性耳下腺炎はいわゆる「おたふく風邪」で、ムンプスウイルスによる飛沫感染症である。両側性の耳下腺腫脹が特徴であり、診断は臨床症状や抗体価（1週間程度要する）で行われる。特効薬はなく対症療法が中心となるが、合併症として難聴、無菌性髄膜炎、大人の場合は精巣炎や卵巣炎に注意が必要である。予防にはMMRワクチンが有効である。一方、小児で発症し、月単位で腫脹を繰り返すものを反復性耳下腺炎と呼び、10代には自然軽快することが多い。（PDF p.2「流行性耳下腺炎」「反復性耳下腺炎」）

化膿性耳下腺炎と高齢者のリスク

口腔内細菌が導管を逆行して感染する逆行性感染により発症する。片側性の腫脹が特徴で、黄色ブドウ球菌などが原因菌となる。唾液分泌が低下した高齢者や、経口摂取が困難な患者に多く見られるため、注意が必要である。（PDF p.2「化膿性耳下腺炎」）

シェーグレン症候群の診断と病態

スウェーデンの眼科医によって報告された自己免疫疾患で、涙腺・唾液腺の分泌能が低下し、眼乾燥（ドライアイ）や口腔乾燥（ドライマウス）を主訴とする。診断には、小唾液腺生検によるリンパ球浸潤の確認、抗SS-A抗体・抗SS-B抗体の陽性判定、シルマーテスト（涙液量）、唾液腺造影でのApple tree appearanceなどが用いられる。関節リウマチなどの他の膠原病を合併することも多い。（PDF p.3「シェーグレン症候群」）

IgG4関連疾患：ミクリッツ病とキュットナー腫瘍

比較的新しい概念であるIgG4関連疾患では、唾液腺領域においてミクリッツ病（涙腺、耳下腺、顎下腺の対称性腫脹）やキュットナー腫瘍（慢性硬化性顎下腺炎）が見られる。血清中のIgG4が高値（135mg/dL超）を示し、病理組織で著名なリンパ球・形質細胞の浸潤と線維化を認めるのが特徴である。（PDF p.3「IgG4関連疾患」）

唾石症と唾液腺腫瘍の概要

唾石症は唾液腺内に結石が生じる疾患で、顎下腺に最も多く発生する。食事の際の腫れや痛みが特徴であり、治療には内視鏡を用いた摘出や、口腔内切開、重症例では顎下腺全摘が行われる。唾液腺腫瘍には良性と悪性があり、良性では多形腺腫が最も頻度が高く、次いでワルチン腫瘍が見られる。悪性腫瘍（癌）も存在するが、多形腺腫は長期間放置すると癌化（多形腺腫由来癌）のリスクがあるため注意を要する。（PDF p.4「唾石症」「唾液腺腫瘍」）
