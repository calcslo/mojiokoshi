全体の詳細なまとめ

症例検討の進め方と本セッションの狙い

症例検討は各グループでプレゼンし、内容が重複しても問題ない方針で進行した。講師は「術前→術中→術後」を連続した流れとして捉え、各段階の問題点と対策を統合して考えることを求めた。
PDF p.1「高齢者の麻酔／症例検討のまとめ」

症例の背景と術前評価（患者因子の整理）

患者は高齢・痩せ（170cm 52kg）で、高血圧（アムロジピン内服）、COPD（喫煙歴）、腎機能低下、認知機能低下、心房細動（AF）で抗凝固療法（エドキサバン）といった併存疾患がある。さらに低栄養（アルブミン低値、体重減少）や、担癌であれば悪液質（カヘキシア）の可能性も含め評価すべき、という整理がなされた。
PDF p.2「術前評価と対応：高齢、担癌、低栄養、高血圧、AF、COPD／気道確保困難」

術前：高齢・認知機能低下への対応（せん妄予防を含む）

高齢者では術後せん妄リスクが高く、術前から認知機能評価を行うことが重要とされた。具体的にはMMSE-JやMoCA-Jで評価し、術前からのプレハビリテーション、せん妄対策を行う。
PDF p.2「MMSE-J、MOCA-Jで認知機能評価／プレハビリテーション／せん妄対策」

術前：低栄養・フレイル、担癌・悪液質（カヘキシア）

低栄養（低アルブミン、短期間の体重減少、筋肉量低下）は術後合併症リスク（感染、肺炎、心疾患、せん妄など）を高める。担癌では慢性炎症により悪液質（カヘキシア）を来し得て、さらなる筋肉量低下・低栄養につながるため、栄養療法とプレハビリテーションで術前から全身状態を改善することが強調された。また悪液質などが疑われる場合、今の時代は緩和ケア介入も重要で、身体面だけでなく精神面の支援も含む。
PDF p.2「低栄養：栄養療法とプレハビリで改善」「担癌：悪液質には緩和ケア介入が重要」

術前：高血圧（術中の乱高下リスク）

高血圧は術中循環変動が大きくなりやすく、術後も内服中断や疼痛などで高血圧が遷延しうるため、術前に血圧を適切に管理する必要がある。
PDF p.2「高血圧：術前に血圧を管理することが必要」

術前：AFと抗凝固薬（中止・再開計画）

AFでは血栓予防のため抗凝固が必要だが、手術出血とのバランスを取り、抗凝固薬の中止と再開計画を立てることが重要とされた。術後に再開を忘れると血栓塞栓症リスクが上がる一方、早すぎる再開は出血リスクがあるため、計画性が必要である。
PDF p.2「AF：抗凝固薬の中止と再開計画を立てる」

術前：COPD（禁煙、呼吸リハ、吸入薬調整）と酸素化低下の背景

COPDでは術前に呼吸リハビリや吸入薬の調整を行う。術中の酸素化低下はCOPDそのものに加え、全身麻酔・筋弛緩・体位・気腹で無気肺が生じやすいことが原因となる、というディスカッションが行われた。特に頭低位（ヘッドダウン）では腹部臓器が横隔膜側へ移動し、機能的残気量（FRC）低下→無気肺リスク増大につながる。さらに気腹で腹圧が上がり横隔膜が挙上し、換気・ガス交換が悪化して酸素化低下やCO2上昇が起こり得る。
PDF p.2「COPD：呼吸リハビリと吸入薬の調整」「気道確保困難：対応策」

術前：気道評価と挿管戦略共有

開口障害、頸部可動域制限、義歯などから気道確保困難が疑われ、事前に挿管戦略を共有し、気道確保デバイス（例：ビデオ喉頭鏡等）の準備を行う重要性が述べられた。なお、覚醒下挿管や外科的気道確保は理論上の選択肢として言及されたが、講師は「近年はデバイスが充実しており、多くの場合、最初から覚醒下挿管は選ばないことが多い」「外科的気道確保は緊急事態の緊急事態」と補足した。
PDF p.3「気道確保：挿管戦略を事前に共有」
PDF p.6「気道確保デバイス／気道確保方法の検討」

術前：貧血（補正・輸血も視野）

高齢で貧血があり出血を伴う手術では、術後の回復が遅く輸血が必要になる可能性を考慮する。術前の貧血の補正が重要と整理された。
PDF p.2「貧血の補正」

ASA-PS（フィジカルステータス分類）の付与

症例の全身状態評価としてASA-PS分類を必ず付与する点が強調された。本症例では合併症の程度からASA-PS 3も妥当となり得る、と議論された。

術中：腹腔鏡・気腹の特有問題

腹腔鏡では気腹による影響として、縦隔気腫、気胸、無気肺、高二酸化炭素血症、不整脈、心拍出量低下、乏尿などが起こり得る。ガス交換悪化では、酸素化よりも先にCO2が上昇しやすい点が言及された。
PDF p.3「腹腔鏡特有問題：縦隔気腫、気胸、無気肺、高炭酸ガス血症、不整脈、心拍出量低下、乏尿」

術中：高度頭低位（ヘッドダウン）の影響

高度頭低位では呼吸への悪影響が大きく、さらに眼圧上昇（脳圧上昇にも注意）などの問題があり、注意深い管理が必要とされた。
PDF p.3「高度頭低位：呼吸への影響、眼圧に注意」

術中：高齢・低栄養・腎機能低下と薬剤投与量調整

高齢では薬剤感受性増大があり、麻酔薬などは減量が必要となる。低栄養・腎機能低下では薬物動態の変化に注意し、代謝・排泄遅延や過鎮静、循環抑制を回避する。
PDF p.3「高齢：薬剤感受性が増大するため減量」「低栄養：薬物動態変化に注意」
PDF p.4「腎機能低下：薬剤代謝と低血圧に注意」

術中：高血圧・循環変動と観血的動脈圧モニタ

高血圧症例では術中の循環変動が大きくなるため、観血的動脈圧モニタリングによる厳重管理が重要とされた。術中低血圧が続くと術後のAKI（急性腎障害）や心筋障害につながるため、特に平均血圧（MAP）が重要であると説明された。
PDF p.3「高血圧：観血的動脈圧モニターを使用し厳重管理」

術中：AF（頻脈発作への対応）

AFでは頻脈発作を起こし得るため、必要に応じてCa拮抗薬やβ遮断薬を使用し、循環管理を行う。
PDF p.3「AF：頻脈時にCa拮抗薬やβ遮断薬を使用」

術中：COPDの換気管理

COPDでは換気設定を入念に行い、特に呼気延長など病態に合わせた人工呼吸設定を行い、術後肺炎など呼吸器合併症を予防する。
PDF p.4「COPD：換気設定は入念に行い、肺炎を予防」

術中：貧血管理（輸血判断）

貧血がある場合、出血量や全身状態に応じて輸血の適時判断が必要である。
PDF p.4「貧血管理：輸血の適時判断が必要」

術中：低体温リスク（痩せ・高齢・末梢循環）

痩せ・低栄養・高齢では体温保持が難しく、低体温になりやすい。低体温は免疫力低下に結びつき、感染リスクにも関係するため注意が必要である、という説明があった。

術後：せん妄・睡眠障害と環境調整、薬物療法

術後はせん妄や睡眠障害が問題となる。最重要の予防策は環境調整（時計・カレンダー提示、家族面会など）である。睡眠障害が生じた場合は早期介入が必要で、第一選択としてメラトニン受容体作動薬（ラメルテオン）、オレキシン受容体拮抗薬（レンボレキサント、スボレキサント）が挙げられた。
PDF p.5「せん妄／睡眠障害：環境調整が重要」「ラメルテオン」「レンボレキサント」「スボレキサント」

術後：循環（AF・高血圧）と内服再開・モニタリング

術後は抗凝固薬の再開、降圧薬の再開を適切なタイミングで行い、継続してモニタリングする必要がある。
PDF p.5「抗凝固薬の再開／降圧薬の再開／モニタリング」

術後：体位関連の肩痛・神経障害の早期発見

高度頭低位や砕石位など特殊体位では、固定器具等により肩の痛みや上肢のしびれなど神経障害が起こり得るため、早期発見と対策が必要とされた。

麻酔方法の選択：全身麻酔を基本に調整

麻酔法は基本的に全身麻酔が第一選択とされ、薬剤はデスフルランまたはプロポフォールが候補となる。プロポフォールは血圧低下に注意が必要。高齢・低栄養・腎機能低下に応じて投与量を減量し、循環動態を厳重に監視する。気道確保困難が予想されるため、気道確保方法を事前に検討しデバイスを活用する。
PDF p.6「全身麻酔：デスフルランまたはプロポフォール」「減量：高齢・低栄養・腎機能低下に応じて調整」「観血的動脈圧モニター」

麻酔薬の回避：ベンゾジアゼピンとせん妄

ベンゾジアゼピン系はせん妄リスクの観点から可能な限り避ける、という方針が述べられた（ただしレミマゾラムは短時間作用で議論の余地がある旨の補足もあった）。
PDF p.6「ベンゾジアゼピン系は可能な限り避ける」

術後鎮痛戦略：マルチモーダル鎮痛と腎機能配慮

鎮痛は多モーダル鎮痛を基本とし、アセトアミノフェン、（腎機能低下では慎重に）NSAIDs、局所浸潤麻酔、末梢神経ブロックなどを組み合わせ、オピオイドを必要最小限に調整する。腎機能低下では、特にモルヒネは腎排泄・活性代謝物の蓄積により血中濃度が下がりにくく、呼吸抑制や傾眠などの副作用が増えるため注意が必要と具体的に説明された。
PDF p.6「多モーダル鎮痛：アセトアミノフェン、NSAIDs、局所浸潤麻酔、末梢神経ブロック」

講師による総括（最終メッセージ）

講師は、術前では認知機能評価（MMSE-J、MoCA-J）、プレハビリテーション、担癌による悪液質（カヘキシア）と緩和ケア介入、高血圧管理、抗凝固薬の中止・再開計画、COPDへの呼吸リハ・吸入薬調整、気道確保困難への事前計画を要点として整理した。術中は腹腔鏡（気腹）と高度頭低位による呼吸・循環への影響（無気肺、CO2上昇、心拍出量低下、乏尿、眼圧上昇等）と、観血的動脈圧を含む厳重モニタリング、薬剤減量、AF頻脈対応、COPD換気設定を確認した。術後はせん妄・睡眠障害（環境調整と薬物）、抗凝固薬・降圧薬再開とモニタリング、体位関連神経障害、そしてMINS・AKI・呼吸器合併症の監視が重要と締めくくられた。
